# Pirhavheen Kumar — Portfolio

A responsive, single-page portfolio built with semantic HTML, CSS and vanilla JavaScript. It has no build step or package dependencies.

## Run locally

From this folder, start a local web server:

```powershell
python -m http.server 4173
```

Then open <http://localhost:4173>.

## Deploy

Upload the project files to any static web host, including GitHub Pages, Hostinger, Netlify, Cloudflare Pages or Vercel. There is no build command or output folder. The `assets/pirhavheen-hero-v2.mp4` file is used by the full-screen portfolio hero and should be included when deploying.

## Portfolio content

Career history, skills, awards, education, certification and project details are based on the supplied resume. The CGI award has no year listed in the resume, so the site leaves it undated.

## Design

The site includes a brief loading intro, a full-screen video hero, and sections for About, Expertise, Skills, Experience, Projects, Recognition and Contact. The navigation supports keyboard use, and the site respects reduced-motion preferences. Google Fonts provide Manrope and DM Mono, with system fallbacks.
